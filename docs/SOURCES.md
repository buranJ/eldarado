# Источники данных

Документ фиксирует, что и на каких основаниях мы собираем. Поведение проверено
22 сентября 2026 года; при изменении страниц или правил источника документ нужно
перепроверить.

## FunPay

Официального API нет. Собираем HTML страниц категорий.

### Область сбора

`robots.txt` FunPay запрещает, среди прочего, шаблон `/*/offer`. Под него
попадает `/lots/offer?id=...` — страница отдельного лота. Страницы категорий
(`/lots/<id>/`) под запрет не попадают, `Crawl-delay` не задан.

По решению оператора страницы конкретных лотов используются только для получения
до четырёх оригинальных скриншотов. Перед промышленным использованием это решение
следует отдельно согласовать с FunPay. Коллектор:

* ходит только на `/lots/<id>/` и `/lots/offer?id=<id>` — это проверяется в коде
  (`FUNPAY_ALLOWED_PATH` в `adapters/source/funpay/config.ts`), попытка запросить
  другой путь бросает ошибку;
* делает один плановый сбор в сутки;
* представляется честным `User-Agent` с контактным адресом;
* держит минимальный интервал между запросами (`MIN_REQUEST_INTERVAL_MS`).

Мы не обходим CAPTCHA и антибот-защиту, не подменяем отпечаток браузера и не
используем ротацию прокси. Если FunPay закроет доступ — идём договариваться.

Из полного каталога выбираются 200 уникальных объявлений с наибольшими ID.
Явной даты публикации в HTML нет; ID выдаются последовательно и используются
как доступный стабильный признак «сначала новые».

### Что отдаёт страница категории

Одна страница содержит весь каталог (на 28.08.2026 — 2001 объявление, 2.4 МБ).
Каждое объявление — ссылка `a.tc-item` с машиночитаемыми атрибутами:

| Источник | Поле | Примечание |
|---|---|---|
| `href` | id объявления | |
| `data-user` | id продавца | |
| `data-auto` | автовыдача | |
| `data-online` | продавец онлайн | |
| `data-f-arena` | арена | |
| `data-f-level` | «уровень» | **семантика не подтверждена**, значения до тысяч |
| `data-f-cup` | кубки | |
| `data-f-card` | карты | |
| `data-f-legcard` | легендарные карты | заполнено не у всех |
| `data-f-namechange` | смена имени | |
| `.tc-desc-text` | заголовок | с авто-суффиксом площадки |
| `.media-user-name` | имя продавца | |
| `.rating-stars` | рейтинг 1–5 | отсутствует, если отзывов нет |
| `.rating-mini-count` | число отзывов | |
| `.media-user-info` | возраст на площадке | «на сайте 2 года» |
| `.tc-price` | цена и валюта | |

Чего на странице категории **нет**: фотографий объявления, описания,
эволюций, героев, гемов, условий передачи. Всё это либо в тексте заголовка
(достаётся AI-анализом на этапе 2), либо только на странице лота.

Коллектор открывает публичную страницу каждого из 200 лотов, берёт до четырёх
оригиналов из `.attachments-list`, сохраняет их в локальное хранилище и связывает
с записью в БД. Если продавец не добавил ни одной доступной картинки, объявление
не сохраняется (или удаляется при повторной проверке).

### Авто-суффикс заголовка

К заголовку продавца FunPay дописывает сводку своих же атрибутов:

```
🌑【🏆10690🏆】【7 ЭВО + 1 ГЕРОЯ】, 26 арена, 1461 уровень, 10690 кубков, 121 карт, 21 лег, Нет
```

Суффикс восстанавливается из уже известных значений атрибутов и удаляется, так
что AI читает только текст продавца. Если точного совпадения нет, заголовок
остаётся нетронутым — мы не угадываем.

### Достоверность атрибутов

Площадка **не валидирует** то, что продавцы вписывают в поля фильтров. В живом
корпусе встречаются `-1` и `8216` карт, `9999` легендарных, арена `100`.
Значения вне правдоподобных диапазонов (`config/sanity.ts`) помечаются как
недостоверные, и объявление не проходит предфильтр — до AI-анализа мусор не
доходит.

Арены 31–35 — настоящие, их продолжают добавлять в игру. Верхняя граница
`36` подобрана по корпусу и требует пересмотра при обновлениях Clash Royale.

## Eldorado

Официальный Seller API существует: офферы (создание, обновление, пауза,
возобновление, удаление) и заказы. Ключ выпускается в кабинете продавца,
документация — по запросу на api@eldorado.gg. Требование доступа — 50 продаж
на площадке (у нас выполнено).

Ключ хранится в `.env` (`ELDORADO_API_KEY`) и в репозиторий не попадает.
