# Иллюстративные постеры

Эти JPEG созданы встроенным генератором изображений для объявлений без исходных фото.
Они не являются официальными изображениями игр и не подтверждают характеристики
конкретного аккаунта. Оригинальные фотографии FunPay всегда имеют приоритет.

Общее задание для генерации: оригинальная цифровая иллюстрация 4:3 для
категории игры, без официальных логотипов, узнаваемых персонажей, водяных знаков
и выдуманных характеристик аккаунта. Темы по файлам:
